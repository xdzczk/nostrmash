# Configuration

Use this page as the environment-variable reference for NostrMash runtimes.
It is generated by `go run ./cmd/configdoc` from `internal/config` metadata.
Read [docs/operations.md](operations.md) for operator workflow and tuning context; use this page as the lookup layer for exact variable names, defaults, and runtime ownership.
Operational values consumed outside `internal/config` such as `LOG_LEVEL`, deployment metadata like `APP_VERSION`, and test-only knobs like `TEST_DATABASE_URL` are intentionally out of scope.
Do not hand-edit this file.
